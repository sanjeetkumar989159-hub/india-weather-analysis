# india-weather-analysis

A Python-based project that fetches real-time weather data for the capitals of Indian states using the OpenWeather API and visualizes the results.

## Features

* Fetches live weather data
* Collects temperature, humidity, pressure, wind speed, visibility, and weather conditions
* Saves data in CSV format
* Generates a temperature and feels-like comparison chart
* Keeps the API key secure using environment variables

## Tech Stack

`Python` `Requests` `Pandas` `Matplotlib` `OpenWeather API`

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/india-weather-dashboard.git
cd india-weather-dashboard
pip install -r requirements.txt
```

Create a `.env` file:

```env
OPENWEATHER_API_KEY=your_api_key_here
```

## Run

```bash
python main.py
```

## Output

* `india_weather_data.csv`
* State-wise temperature comparison chart
